# Community code of conduct

RealityCheck welcomes people who want to make Web quality evidence more trustworthy. Participation requires respectful, evidence-based collaboration.

## Expected behavior

- Be specific about behavior, evidence, and tradeoffs; critique ideas and code, not people.
- Make room for different experience levels, languages, accessibility needs, and technical backgrounds.
- Protect private application data. Redact credentials, customer information, private URLs, screenshots, and report artifacts before sharing.
- Disclose uncertainty. Unsupported scenarios, unverified fixes, and heuristic observations must be described honestly.
- Respect testing authorization. Do not use this project to pressure others into testing systems they do not own or have permission to assess.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate humiliation, doxxing, publishing secrets or private evidence, impersonation, spam, and knowingly unsafe testing instructions are not acceptable in project spaces.

## Enforcement

Report conduct concerns privately to the repository owner through an available private GitHub contact. Do not put sensitive incident details in a public issue. Maintainers may edit or remove content, close discussions, limit participation, or ban contributors when needed to protect the community and project safety boundary.

Enforcement decisions should consider context, impact, repetition, and opportunities to repair harm. Good-faith technical disagreement is not misconduct; persistent personal attacks or unsafe disclosure are.

This policy applies to repository issues, pull requests, discussions, reviews, and other spaces where someone is representing the RealityCheck project.
