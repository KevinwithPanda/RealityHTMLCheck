## Portable field note

This repository-authored note tests a real Pandoc export in which the local stylesheet and diagram are embedded into one shareable HTML file.

### Offline evidence

![Three bounded stages: collect, verify, and share.](assets/evidence-flow.svg)

The generated document should retain the diagram and the small visual treatment without requesting a local or remote attachment.

### Review checklist

- Confirm the page opens without a network connection.
- Confirm the diagram has useful alternative text.
- Confirm no machine-specific path appears in the generated HTML.
