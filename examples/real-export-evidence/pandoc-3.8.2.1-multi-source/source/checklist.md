## Release checklist

This second repository-authored source file supplies the operational checklist combined into the same generated page.

1. Freeze the exact input files.
2. Record the exporter version and executable hash.
3. Compare raw and canonical-line-ending output hashes.
4. Run RealityCheck again against the captured HTML.

### Scope statement

Passing this scenario proves only the recorded multi-source command and captured bytes. It is not a claim about unrelated exporters or arbitrary input documents.
